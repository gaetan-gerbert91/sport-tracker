# 🏃 Sport Tracker

## Description

Sport Tracker est une application web permettant aux sportifs de suivre leurs performances, leurs records personnels et leurs prochaines compétitions.

Le projet est développé dans le cadre de mon portfolio afin de mettre en pratique mes compétences en développement web.

## Fonctionnalités prévues

- Authentification
- Gestion des performances sportives
- Historique des activités
- Gestion des compétitions
- Tableau de bord personnalisé
- Statistiques
- Suivi des records personnels

## Technologies

### Front-end
- React

### Back-end
- Java
- Spring Boot

### Base de données
- PostgreSQL
